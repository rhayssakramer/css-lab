Hacks de CSS que Você Precisa Saber

1. CSS Custom Properties (Variáveis)

Defina variáveis CSS e reutilize-as em todo o projeto. Fácil de manter e modificar.

:root { --primary: #ff6b35; } .btn { color: var(--primary); }

2. Calc() para Layout Responsivo

Combine unidades diferentes para criar layouts flexíveis sem media queries.

width: calc(100% - 2rem); padding: calc(1rem * 2);

3. Grid com Auto-fit

Crie grids responsivos sem media queries usando auto-fit.

grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));

4. Aspect Ratio

Mantenha proporções de aspecto sem hackear com padding.

aspect-ratio: 16 / 9;

5. :has() Selector

Selecione elementos baseado no conteúdo que contêm (seletores pai).

.container:has(> img) { display: flex; }

6. Backdrop-filter para Glass Effect

Crie efeitos de vidro com blur e glassmorphism.

backdrop-filter: blur(10px); background: rgba(255,255,255,0.1);
